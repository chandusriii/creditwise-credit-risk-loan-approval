# Project Outputs

This folder is intended for visual outputs generated from the project notebook.

Recommended organization:

```text
outputs/
├── eda/
│   ├── loan_approval_distribution.png
│   ├── numerical_distributions.png
│   ├── correlation_heatmap.png
│   └── feature_relationships.png
│
├── models/
│   ├── model_comparison.png
│   ├── logistic_regression_confusion_matrix.png
│   ├── knn_confusion_matrix.png
│   └── naive_bayes_confusion_matrix.png
│
└── feature_engineering/
    └── feature_engineering_impact.png
```

The images should be generated from the actual notebook/data rather than manually recreated, so that the visuals remain consistent with the reported results.
